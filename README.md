# 考勤统计桌面工具

## 使用说明
1. 双击 `启动考勤统计工具.sh` 或运行 `python3 考勤统计工具.py`
2. 点击「📂 选择考勤Excel」→ 选择钉钉/飞书导出的考勤文件
3. 自动解析并显示统计表格
4. 点击某人可查看详细打卡明细
5. 点击「📤 导出汇总Excel」可保存报表

## 功能
- ✅ 自动解析考勤 Excel（钉钉/飞书导出格式）
- ✅ 统计每个人的出勤率、迟到、缺卡、加班
- ✅ 顶部卡片快速查看关键数据
- ✅ 点击表头可按列排序
- ✅ 点击查看单人每日打卡明细
- ✅ 支持导出汇总 Excel
- ✅ 红/橙/绿三色标注异常程度

## 环境要求
- Python 3.6+
- pip 包: pandas, openpyxl
